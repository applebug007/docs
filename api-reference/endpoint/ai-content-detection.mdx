---
title: "AI Content Detection - Base64"
---

Detect AI-generated content using base64-encoded images.

## Parameters

<ParamField body="image_data" type="string" required>
  Base64-encoded image data
</ParamField>

<ParamField header="x-api-key" type="string" required>
  Your API key
</ParamField>

## Response

```json
{
  "likely_ai_generated": true,
  "confidence_score": 0.91,
  "processing_time_ms": 312
}
```

## Example

```bash
curl -X POST "https://api.scam.ai/detect" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"image_data": "iVBORw0KGgoAAAANSUhEUgAA..."}'
```
