## What Are Deepfakes?

Deepfakes are AI-generated videos where a person's face is replaced with someone else's face. They're used for:

- **Identity impersonation** - Fake CEO videos for fraud
- **Disinformation** - False political statements  
- **Scams** - Fake testimonials and endorsements
- **Privacy violations** - Non-consensual content

## Quick Start

### Image Detection
```bash
curl -X POST "https://api.scam.ai/api/defence/faceswap/predict" \
  -H "x-api-key: YOUR_API_KEY" \
  -F "files=@/path/to/your/image.png"
```

### Video Detection
```bash
curl -X POST "https://api.scam.ai/api/defence/video/detection" \
  -H "x-api-key: YOUR_API_KEY" \
  -F "video=@/path/to/your/video.mp4"
```

### Response
```json
{
  "is_deepfake": true,
  "confidence": 0.87,
  "processing_time_ms": 1250
}
```
